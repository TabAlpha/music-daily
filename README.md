## What each release carries

| File | What it is |
|---|---|
| `*.mp3` | The master, 320 kbps |
| `cover.png` | Cover art, 3000×3000, title typeset on the image |
| `lyrics.txt` | The full original lyrics |
| `meta.json` | Genre, tempo, key, duration, generators, cost, loudness and intelligibility numbers |

## Features

- **Original only**: original composition and lyrics; no samples and no reference to existing songs or artists in the prompt.
- **Mastered to a target**: -14 LUFS integrated, true peak at or below -1 dBTP, no interior silences.
- **Checked for intelligibility**: lyrics are transcribed back with speech recognition and scored for word recall.
- **Honest metadata**: tempo and key are marked as requested, not measured; per-song cost is recorded.
- **Genre rotation**: a different genre each day.

See [SKILLS_USED.md](SKILLS_USED.md) for the tools and techniques behind each release.
